# Quick Start
To run the program do the following:
## Setup 
(If you don't have make you may need to run: choco install make)
1. Run in powershell:
make setup
make ui


2. Navigate to [localhost](http://127.0.0.1:5000/)

3. Drop an audio file into the drop box

## QLC
Install QLC+
Under the qlc_plus folder open csc475 v2.qxw

Now when running an audio file the lights in the scene should react
